✨UPDATE✨ uwuPromptr 2.0.0: the apps, rebuilt
cue.uwuapps.org

Everywhere:
- Report a bug, with a screenshot of any page and a report ID to quote
- A short tour of each page the first time you open it
- The app's remote drives the website's prompter, and the other way round

Android app:
- Every screen built for Android: quick to open, smooth to scroll, offline from the first open
- Material You by default, with the UwU Apps look a switch away in Theme
- An Updates page with what's new in every version
- A notification the moment a new version is out, if you'd like one
- Your scripts and settings come across from 1.0.0 by themselves

Windows, macOS and Linux apps:
- A command bar (Ctrl+K) to search every script and run any command
- Your scripts beside the prompter on a wide window
- A mini remote that stays on top, for a prompter on another screen
- Start and stop from the taskbar, the tray countdown, and your scripts in the Jump List and Dock

Already on 1.0.0? It updates itself.

Download the apps and view patch notes: github.com/augy-studios/uwuPromptr/releases/latest
