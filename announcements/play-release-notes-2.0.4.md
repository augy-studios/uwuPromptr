# Google Play release notes, 2.0.4

Paste the block below into the release's **Release notes** box in Play Console (GOOGLE-PLAY.md,
section 10). Play allows 500 characters per language; this is about 330. The store listing is in
English (United Kingdom) only, so the tag is `en-GB`, as in 2.0.0.

```text
<en-GB>
• The windows and the script editor now keep their last rows above the navigation bar
• New in Prompter settings > Android app: a slider that moves the bottom rows up or down, for phones where they sit too low or too high
• No second gap under the script with a tray open
</en-GB>
```
